# 交付前檢查清單

## 內容
- [ ] 每個數字都能在原文找到（錨點標黃的地方真的寫著那個數字）
- [ ] 論文自相矛盾或和其他文獻不一致的地方，有在講稿點出來
- [ ] 有講研究設計與限制，沒有把相關說成因果
- [ ] 片頭有「AI 製作、未經專業審查」聲明，播放頁 disclaimer 也有
- [ ] 沒有病人可識別資料、私人筆記

## 風格（詳見 style-principles.md）
- [ ] 每一幕能用一句話說出「要觀眾記住什麼」
- [ ] 沒有 emoji、左色條卡片、漸層背景、自畫插圖、假數據
- [ ] 每句只有一個焦點，其他元素有變淡

## 投影片
- [ ] 逐張看過 `video/slides/slide_NN.png`：沒有字被切掉、沒有元素擠出畫面
- [ ] 每一幕最後一張，所有元素都已出現；沒變淡的那個正是這句在講的東西
- [ ] 右上角「原文 p.」頁碼和這句的出處一致

## 聲音與影片
- [ ] 隨機聽 5 句以上：數字、縮寫、英文藥名念得對
- [ ] 影片長度 ≈ 各句音訊長度總和；結尾沒有被截掉
- [ ] 字幕和聲音對得上（抽看開頭、中段、結尾）

## 播放頁（用 `pe.py serve` 開，不要用 http.server）
- [ ] 播放時右邊原文會跟著捲動，黃底是這一句、橘底那一行會往下走
- [ ] 拖曳影片進度條後，原文會跳到對應位置
- [ ] 點原文的黃底段落，影片會跳回講解那一句
- [ ] 手機寬度（約 400 px）版面正常、章節可展開
- [ ] 深色模式文字看得清楚

## 發佈（使用者同意後）
- [ ] 論文授權允許散布 PDF 頁面圖；不允許就不要發佈
- [ ] `publish/` 每個檔案都在平台上限內（Artifact 15 MB）
