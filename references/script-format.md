# script.py 講稿格式與寫作規則

`script.py` 是唯一手寫來源，定義 `SCENES`（幕的清單）。範本在 `templates/script.py`，裡面有元素的小函式。

## 一幕（scene）

```python
{
  "kick": "§3 Results",            # 左上小標：章節或來源
  "title": "主要結果",              # 大標（可含 <b>、<br>）
  "sub": "Primary outcome",        # 選填：英文副標
  "rows": [ [元素, 元素], [元素] ], # 版面：每個內層 list 是一列，列內元素左右並排
  "steps": [ 句, 句, ... ],        # 逐句旁白，一句＝影片的一個狀態
}
```

- 一幕 3–6 句，最多 3 列。超過就拆成兩幕。
- 一篇論文常見的分幕：開場（問題與為什麼重要）→ 背景或機轉 → 方法（設計、族群、終點）→ 主要結果（每個重要數字一幕）→ 次要結果與安全性 → 限制 → 臨床意義／帶走三件事。總長 8–15 分鐘（約 60–120 句）為宜。

## 一句（step）

| 欄位 | 用途 | 規則 |
|---|---|---|
| `t` | 字幕 | 一兩句話、約 60 字內；數字照論文寫（40%、HR 0.62） |
| `s` | 念稿 | 省略時同 `t`。凡是數字、百分比、單位、符號、縮寫，都改成念得出來的樣子：「40%」→「百分之四十」、「HR 0.62」→「風險比零點六二」、「≥ 4」→「四分以上」、「mg/kg」→「每公斤幾毫克」 |
| `a` | 原文錨點 | 見下表；**每個數字都要有錨點** |
| `show` | 這句浮現的元素 id | 會累加：之前出現的元素會一直留著 |
| `focus` | 這句的焦點 | 省略時＝`show`；**焦點以外已出現的元素會自動變淡**。整幕總結要全部清楚時寫 `"focus": []` |

## 錨點 `a`

| 寫法 | 意思 |
|---|---|
| `"原文中的一句話"` | 找到這句、標黃這幾行。從 `src/text.md` 原樣複製；引用括號 [12] 可以省略 |
| `["開頭幾個字", "結尾幾個字"]` | 從開頭到結尾的整段（跨行、跨欄、跨頁都可以） |
| `{"page": 3}` | 只把原文捲到第 3 頁，不標行（開場、總結用） |
| `{"page": 3, "rect": [x0, y0, x1, y1]}` | 標一個固定框，給圖、表用；座標（pt）見 text.md 的「圖片區塊」 |

- 找字會從上一句的位置往後找，所以講稿大致照原文順序寫最穩；同一句話在原文出現兩次時，會挑上一句之後的那一次。
- 引句太短（少於 15 個英數字）容易對錯位置；太長則容易因為換行斷字對不到——用「開頭／結尾」寫法最保險。
- 表格內容常是一格一格的，建議用 `rect` 框整張表。

## 版面元素

| 函式 | 長相 | 參數 |
|---|---|---|
| `stat(id, n, l, tone, w)` | 大數字＋說明 | n：數字字串；l：說明（可 `<br>`） |
| `card(id, h, b, tone, w)` | 標題＋內文卡片 | b 可含 `<b>` 強調 |
| `bar(id, l, v, t, tone)` | 橫條圖一列 | v：0–1 的長度；t：右側數值文字 |
| `pts(id, l, n, tone, max_n)` | 計分方塊 | n 格實心、其餘虛線（例：ICBD 2 分） |
| `chip(id, t, tone)` | 膠囊標籤 | 流程圖的節點 |
| `arrow(id, t)` | 箭頭 | 放在兩個 chip／card 中間 |
| `note(id, t, tone)` | ⚠ 提醒框 | 陷阱、限制、易混淆處 |
| `quiz(id, src, stem, ans, why)` | 考題卡 | 例：國考題、自我測驗 |
| `img(id, src, cap, w)` | 圖片 | src 相對專案，通常是 `crop` 裁的原文圖 |
| `group(id, h, els, w)` | 帶標題的框 | 把幾個 bar／pts 收在一起 |
| `stack(els, w)` | 直向堆疊 | 一欄放好幾張 card |

- `tone`：`red`、`blue`、`amber`、`green`、`gray`、`ink`。紅＝重點或負面、藍＝中性資訊、綠＝正面結果、琥珀＝注意、灰＝旁註。
- `w`：同一列中的寬度比例。
- 每個元素都要有唯一的 `id`（`stack` 除外）。

## 寫作規則（繁體中文自然口語）

完整的生產原則（簡潔、重點、沒有 AI 味）見 [style-principles.md](style-principles.md)。

1. **一句一件事**。觀眾邊看邊聽，一句只講一個概念或一個數字。
2. **先講結論再講數字**：「這個藥比較有效：一年緩解率百分之七十，對照組百分之四十三。」
3. **說人話**：第一次出現的術語先用一句白話解釋（「葡萄膜，是眼球中間那層富含血管的組織」）。英文專有名詞可以保留，例如藥名。
4. **不加油添醋**：論文沒寫的不說；自己的推論要標明「我的解讀」。論文自相矛盾時要點出來，不要選一個講。
5. **限制一定要講**：研究設計、樣本、偏誤、能不能外推到我們的病人。
6. 開場第一句說明「本片由 AI 製作、內容未經專業審查」（放在 `card` 並在念稿說一次）。
7. 念稿避免括號、斜線、破折號：它們會被唸成停頓或怪音（工具會自動把括號和斜線換成逗號，但主動寫乾淨最好）。
